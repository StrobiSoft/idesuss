# 2026-09-27 — Visual direction milestone

## Milestone
Az Idesüss vizuális identitása új szintre lép: a projektet többé nem személyes weboldalként, hanem sofőrközpontú digitális platformként tervezzük.

## Döntés
A cél egy **Modern Utility + Subtle Vintage Transit** vizuális nyelv:
- professzionális, közlekedési/információs rendszer érzet;
- sötét, visszafogott navy/charcoal alap;
- meleg, finom akcentusok;
- nagy információs sűrűség, de világos hierarchia;
- kevés dekoráció, több funkció;
- finom vintage/terminál-hangulat, nem retró utánzat;
- desktop és mobil ugyanazon design-rendszer szerint.

## Fő UX elvek
1. A platform elsődleges ereje az információ.
2. A funkciók modulokba szerveződnek.
3. A legfontosabb kezelőszervek azonnal érthetők.
4. A nyelvválasztó látható, de nem domináns.
5. A státuszok és időadatok vizuálisan egységesek.
6. A mobil UI sofőrbarát: nagy érintési célok, gyors elérés, kevés felesleges lépés.
7. A főoldal dashboardként is működik, nem csak landing page-ként.
8. A CSS többé nem ad hoc: közös design tokenek, komponensszabályok és spacing skála alapján épül.

## Fő modulprioritás
- Kezdőlap / Dashboard
- Ferry Board
- Rail / RoLa Board
- Rádió
- Tools
- WebApp
- Közösség / profil funkciók

## Tools irány
A Tools külön modult kap. Tervezett elemek:
- számológép;
- naptár;
- napló;
- jegyzetek;
- útvonalnapló;
- sebességtúllépés / tachográf esemény visszaszámláló;
- később opcionális naptárszinkron és helyalapú napi napló.

## Ferry + RoLa
A Ferry Board és a Rail/RoLa Board testvérmodulok:
- honnan → hova;
- szolgáltató;
- indulás / érkezés;
- státusz;
- típus;
- később booking.

## Nyelvválasztó
A jelenlegi túl hangsúlyos nyelvválasztó helyett kompakt kontroll:
- zászló + rövid nyelvkód;
- dropdown;
- ugyanaz a közös nyelvi állapot minden platformoldalon.
