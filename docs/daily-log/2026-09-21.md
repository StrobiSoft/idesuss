- Product direction expanded: make Idesüss Radio installable as a PWA. The PWA will use the operating system's media surface outside Idesüss rather than trying to draw a custom web overlay above other apps.

- Defined a future structured Bug Report entry point with subject, max-1000-character description, and automatically captured technical metadata; backend implementation remains pending.

- Truly uninterrupted audio across separate full-page Idesüss documents requires a persistent application shell/navigation architecture; backgrounding or locking the same live document is a different case.
- Bug-report Supabase schema/RLS and abuse controls are not yet implemented.
- Social/friends work remains paused until the current Radio/auth work is complete.
